# CS 330: Computational Graphics and Visualization Portfolio

## Project Overview
For my CS 330 final project, I created a 3D desk workspace using C++ and OpenGL in Visual Studio. My scene includes a desk, laptop, coffee mug, lamp, and potted plant. I used basic shapes to build recognizable objects, then added textures, lighting, and camera controls to make the scene interactive.

## How do I approach designing software?
This project taught me to plan before writing all of the code. I started with a desk scene and broke each object into simpler shapes, such as boxes for the laptop and desk, cylinders for the mug and plant pot, and cylinders and a cone for the lamp. I learned how important proportions, positioning, and consistent coordinates are when several objects need to fit together. I built the basic scene first and then worked on the details. I can use this design process in future projects by breaking a large idea into smaller pieces, building a working foundation, and improving it in stages.

## How do I approach developing programs?
I learned to test changes frequently instead of trying to finish everything at once. During the milestones, I worked on transformations, keyboard and mouse navigation, textures, materials, and lighting. I made adjustments as I went because the scene did not always look or behave the way I expected at first. For example, aligning objects with the tabletop and improving visibility from different camera angles took several changes. I also learned how reusable functions and separating responsibilities between ViewManager and SceneManager can make a program easier to understand. By the final milestone, I was thinking more about how all the features work together instead of focusing on one object at a time.

## How can computer science help me in reaching my goals?
My goal is to become a software developer, and this course gave me more hands-on experience with C++, Visual Studio, problem-solving, and user interaction. I learned how coordinates, transformations, textures, and lighting come together to produce a visual result. These skills can help me in future classes because they require planning, testing, and debugging. Professionally, even if I do not work directly in graphics, I can apply the same habits to building applications, organizing code, troubleshooting problems, and improving software based on user needs. This project also gives me a visual example of my work to share with future employers.
